# Growth Report — handoff template

What to print to chat after the build finishes. Keep it to **2-3
sentences** plus the artifact link — the report does the talking.

## Template

```
[<Store Name> growth report](computer:///<abs-path-to-html>)

Revenue <current> (<signed WoW%>), MER <current> (<signed WoW%>). The most
material driver this week is <top-breaking-or-working-driver>. Live artifact
created and a daily 08:00 refresh is scheduled.
```

## Example

```
[Acme Threads growth report](computer://<workspace>/acme-threads-growth-report-2026-05-14.html)

Revenue <X> (−<N>%), MER <X> (−<N>%). The most material driver this week is
returning-customer revenue contracting while acquisition spend held flat —
blended MER fell even though new-customer ROAS was stable. Live artifact
created and a daily 08:00 refresh is scheduled.
```

## What NOT to print

- Don't restate the metric framework in chat — every row is in the report.
- Don't repeat the headline KPIs in prose beyond the one-line summary — the
  user is about to open the report.
- Don't explain the methodology — the footer + dashboard-spec.md cover that.
- Don't ask follow-up questions in the hand-off — the report's narrative
  answer already frames the next moves.
